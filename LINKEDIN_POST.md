🚀 **Project Completed: Weather Data CLI | Python + API Integration**

I built a Weather Data CLI that retrieves current weather information for a user-provided city using the OpenWeatherMap API.

**Tasks completed**
- Integrated a third-party weather API using Python `requests`
- Processed JSON responses and formatted the results for clear terminal output
- Added error handling for invalid city names, missing/invalid API keys, network timeouts, server errors, and API rate limits
- Kept credentials outside the source code using environment variables
- Added a Flask web interface and health-check endpoint to make the project demonstrable through a Render deployment
- Added automated tests and deployment instructions

**Key features**
🌡️ Temperature and feels-like temperature  
🌤️ Current conditions, humidity, wind speed, and pressure  
🛡️ API key safety and helpful error messages  
💻 CLI plus a responsive web demo  
☁️ Render deployment configuration

**Technologies used:** Python, Requests, Flask, Gunicorn, OpenWeatherMap API, pytest, Git, GitHub, Render.

This project helped me practise API integration, JSON processing, functions, exception handling, environment configuration, testing, and deployment.
